# Student Grade Analyzer

A lightweight Python script designed to process student test scores and generate statistical insights, including class averages, top/lowest performers by name, and passing percentages.

## Features
* Calculates overall class average.
* Identifies top and lowest performing students along with their names.
* Determines class pass rate based on a 50% passing threshold.

## Requirements
* Python 3.8+

## Usage
Run the script directly from your terminal:
```bash
python main.py
